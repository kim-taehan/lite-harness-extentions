플러그인 가이드

Lite Harness 에 화면 · AI 도구 · 언어를 더하는 플러그인을 만드는 법. 가이드마다 하나를 처음부터 끝까지 만들고, 15~30분이면 따라 할 수 있습니다.

시작하기

위에서부터 순서대로 읽으면 패널 → AI 도구 → 팩 → 배포까지 이어집니다.

패널

첫 패널 플러그인 만들기

plugin.json 과 한 파일짜리 index.html 로 오른쪽 패널 탭을 만들고, 앱 통로로 값을 저장하고 프로젝트 이름을 읽고 AI 에게 말을 보냅니다.

15분storage · project · chat AI 도구

MCP 플러그인 만들기

AI 가 부를 수 있는 도구를 MCP 서버로 싣습니다. 설정 칸 · 비밀 값 · [연결 확인] · 같이 설치되는 스킬, 그리고 build.mjs 로 한 파일에 묶기까지.

30분mcp · settings · skills 팩

언어 팩 · 문법 팩 만들기

코드 없이 데이터만 담는 플러그인. 앱 문구를 다른 언어로 바꾸는 언어 팩과, 파일 개요가 새 언어를 읽게 하는 tree-sitter 문법 팩.

20분type: locale · grammar 배포

저장소로 내보내기

만든 플러그인을 이 저장소에 올려 앱의 [플러그인 둘러보기] 에 보이게 합니다. 분류 · 바뀐 것 · npm run release · 버전 규칙.

10분catalog.json · dist
